# Foosball tables: manual app check

Run once the Clerk keys are in the AppHost user-secrets. Local only: placeholders, no real hosts.
Then run `npm run e2e` in `frontend-beta/` on `main` and on this branch, and compare.

**Setup.** `dotnet run --project local-dev/MMRProject.AppHost`. Sign in as an org Owner (A). Have a
second account (B, plain member) in a private window, and a phone or narrow window (≤ 390 px) for
the player screens. The twin is in the `office-rivals/mmr-hardware` repo (private): clone it
next to this one (`../mmr-hardware`) or set `HARDWARE_DIR` to its path, `make` once in
`$HARDWARE_DIR/twin`, and run the `./build/twin` commands below from there. `HOST` below is the
frontend's URL from the Aspire dashboard; `API` is the API's.
