## New issues from round 3

None that changes the parts or the wiring:
- The board netlist is identical to round 2 (my checker, `perfboard.py` diff: a comment only).
- The fuse, the JST pair and the OLED wiring all check out (above).
- The OLED draw task, plan C at 3 ms and in-ball reads only while D8 sees the ball are firmware choices. The twin
  shows 0/60 missed 9 ms balls with the screen on (`twin/reports/plan-c-2026-10-18.md`, "Update"), and a bench scope
  confirms it.

Doc nits, fixable any time and none blocking the purchase:
1. dimensions.md:72 still gives the battery lead "bend r 5.6". Mechanical's `LEAD_R_MIN` is now 7 for the Adafruit 6181
   pair.
2. Header count: ASSEMBLY.md:88 and bom.md:34/:269 still include "J_BAT 3" / "3 keyed headers". It's harmless, since it
   over-buys.
3. Firmware README:186 says "3650 keeps the rail ≥ 3.0 V". :244 says "drawer out" for the USB-only test. :225 still
   says "3.45 V + High + Wi-Fi: no brown-out" (the gate is now at the cutoff, at 11 dBm).
4. SLED-ASSEMBLY:188 says "press the PH latch and pull". A JST-PH wire-to-wire pair has a friction lock, no release
   lever: grip both housings, never the wires.
5. sled.py comments (:10, :105, :138, :512, :520) still mention pogo pins. The code is updated; only the comments are
   stale.
