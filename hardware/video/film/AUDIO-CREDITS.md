# Audio credits

Every sound in the film is generated by code in this folder (English only since 2026-10-18). No samples or third-party recordings are used.

| Track | How it's made | Licence |
|---|---|---|
| English narration: `assets/audio/en/vo/*.wav`, `assets/audio/en/vo.wav` | Text-to-speech from `SCRIPT.md` via `tools/vo.py en`: [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) through `npx hyperframes tts` (voice `bm_george`), run locally. The drawn-out "Nooope." (L21) is Kokoro's "Nope." with its vowel time-stretched by ffmpeg `atempo` | Kokoro-82M weights: Apache-2.0. The generated speech is our output. |
| `assets/audio/<lang>/sfx.wav` (bead click, beam bip, ball roll, table rattle, whoosh, ding, pop, key taps, thud) | Synthesized from sine tones and filtered noise in `tools/sound.py` | Same licence as this repository (our own code and output) |
| `assets/audio/<lang>/sfx.wav`: the goal counter's buzzer (goal chirp, press tick, undo) | ux's `BUZZER` sounds (`ux/sounds.py`, phase 1 B3) through the firmware's player and a CMT-1209 transducer model in `video/sounds/tools/buzzer.py` | Same licence as this repository (our own code and output) |
| `assets/audio/<lang>/music.wav` (pizzicato bed, C–Am–F–G at 96 bpm) | Karplus-Strong plucked-string synthesis in `tools/sound.py`, fixed seed, so it's deterministic | Same licence as this repository (our own code and output) |

Timing only (nothing from these ends up in the films): word onsets are measured with
[Parakeet TDT 0.6B v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) (NVIDIA, CC-BY-4.0) via
`npx hyperframes transcribe -e parakeet` in `tools/words.py`.

The sled stills (`assets/sled/*.png` + `points.json`) are rendered from mechanical's model (`mechanical/sled.py`) by
`tools/sled_renders.py` (command in its docstring); re-run it when the sled changes.

Rebuild: `python3 tools/vo.py en && python3 tools/words.py en && python3 tools/retime.py en && python3 tools/sound.py en`
(needs the local venv: `uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python kokoro-onnx soundfile`).
