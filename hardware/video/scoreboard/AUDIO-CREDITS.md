# Audio credits

Every sound in this film is generated by code. No samples or third-party recordings are used. The tools are
the goal-counter film's (`video/film/tools/`), run with `FILM_DIR` pointing at this folder.

| Track | How it's made | Licence |
|---|---|---|
| Narration: `assets/audio/en/vo/*.wav`, `assets/audio/en/vo.wav` | Text-to-speech from `SCRIPT.md` via `tools/vo.py en`: [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) through `npx hyperframes tts` (voice `bm_george`), run locally | Kokoro-82M weights: Apache-2.0. The generated speech is our output. |
| `assets/audio/en/sfx.wav`: the board's sounds (Goal, Won, Undo, Scan, Joined, Not joined, Saved) | ux's v2 earcons (`ux/SOUNDS-V2.md`): ux's reference WAVs from `ux/sounds.py` (local synthesis), used as they are | Same licence as this repository (our own code and output) |
| `assets/audio/en/sfx.wav`: key clicks, table rattle, thud, whoosh, pop | Synthesized from sine tones and filtered noise in `tools/sound.py` | Same licence as this repository |
| `assets/audio/en/music.wav` (pizzicato bed, C–Am–F–G at 96 bpm) | The goal-counter film's bed: Karplus-Strong plucked-string synthesis in `tools/sound.py`, fixed seed | Same licence as this repository |

Timing only (nothing from it ends up in the film): word onsets are measured with
[Parakeet TDT 0.6B v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) (NVIDIA, CC-BY-4.0) via
`npx hyperframes transcribe -e parakeet` in `tools/words.py`.

The board's screens (`assets/screens/`) are drawn by ux's mockup generator (`ux/mockups.py`) through
`tools/screens.py` (`uv run tools/screens.py`).

Rebuild (from `video/film`): `FILM_DIR=../scoreboard python3 tools/vo.py en`, then `tools/build.sh scoreboard`.
