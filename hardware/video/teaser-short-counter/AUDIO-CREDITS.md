# Audio credits

The goal-counter short teaser has no voice and no music: only sound effects, all generated by code (no samples or
third-party recordings). `tools/sound.py` places them using the goal-counter film's synthesizers
(`video/film/tools/sound.py`).

| Sound | How it's made | Licence |
|---|---|---|
| The goal chirp | The goal counter's own buzzer sound (ux's `BUZZER` goal, `ux/goal-counter-phase1-2026-10-17.md` B3) through the firmware's player and a CMT-1209 model: `video/sounds/tools/buzzer.py` | Same licence as this repository |
| Drone, beam ticks, roll, thud, ding | Sine tones and filtered noise | Same licence as this repository |

Picture: the end card's crest is the project's own icon (`frontend-beta/public/android-chrome-512x512.png`).
Rebuild (from `video/film`): `sh tools/build.sh teaser-short-counter`.
