# Audio credits

The teaser has no voice and no music: only sound effects, all generated by code (no samples or third-party
recordings). `tools/sound.py` places them from `tools/cues.json` using the goal-counter film's synthesizers
(`video/film/tools/sound.py`).

| Sound | How it's made | Licence |
|---|---|---|
| The board's sounds (Goal, Won, Undo, Scan, Joined, Saved) | ux's v2 earcons (`ux/SOUNDS-V2.md`): ux's reference WAVs from `ux/sounds.py` (local synthesis), as they are | Same licence as this repository |
| Bead clack, key clicks, thud, whoosh, pop, ding, beam bip | Sine tones and filtered noise |
| Server "thinking" (relay ticks + blips), packet zips, tiptoe plucks | Sine tones and sweeps only |
| The vault alarm (a gag, not a board sound) | Two-tone square wave | Same licence as this repository |

Board screens: ux's mockup generator (`ux/mockups.py`), copied from the scoreboard film, plus `allin-modes`
from `tools/screens.py`. Rebuild (from `video/film`): `sh tools/build.sh teaser`.
