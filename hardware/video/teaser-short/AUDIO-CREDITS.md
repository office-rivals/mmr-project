# Audio credits

The short teaser has no voice and no music: only sound effects, all generated by code (no samples or third-party
recordings). `tools/sound.py` places them using the goal-counter film's synthesizers (`video/film/tools/sound.py`).

| Sound | How it's made | Licence |
|---|---|---|
| The board's sounds (Goal, Scan, Joined) | ux's v2 earcons (`ux/SOUNDS-V2.md`): ux's reference WAVs from `ux/sounds.py` (local synthesis), as they are | Same licence as this repository |
| Drone, beam ticks, key clicks, thud, ding, roll, the key light's swell | Sine tones and filtered noise | Same licence as this repository |

Pictures: two board screens from ux's mockup generator (`ux/mockups.py`, copied from the teaser); the end card's
crest is the project's own icon (`frontend-beta/public/android-chrome-512x512.png`).
Rebuild (from `video/film`): `sh tools/build.sh teaser-short`.
