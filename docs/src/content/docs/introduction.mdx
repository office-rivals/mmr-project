MMR Project is a self-hosted app for running competitive leagues around office games. Players report match results, the app rates them with OpenSkill, and a matchmaking queue splits the players waiting to play into teams balanced by rating. Leagues live inside organizations and run in seasons, with a leaderboard per season.

You host every part of it yourself except sign-in, which uses [Clerk](https://clerk.com).

## The services

| Service | What it does | Source |
| --- | --- | --- |
| Frontend | React 19 and TanStack Start web app, served by a Node server | [`frontend-beta/`](https://github.com/office-rivals/mmr-project/tree/main/frontend-beta) |
| API | ASP.NET Core API: business logic, data access and the background matchmaking worker | [`api/MMRProject.Api/`](https://github.com/office-rivals/mmr-project/tree/main/api/MMRProject.Api) |
| MMR API | Go service that the API calls to calculate rating changes | [`mmr-api/`](https://github.com/office-rivals/mmr-project/tree/main/mmr-api) |
| PostgreSQL | Stores all application data; the only stateful service | — |
| Clerk | Hosted sign-in; the API validates the JWTs Clerk issues | External |

The browser only talks to the frontend. The frontend's server calls the API with the signed-in user's Clerk token, and the API calls PostgreSQL and the MMR API.

## About the frontend

These docs are written for the beta frontend in `frontend-beta/` and call it "the frontend" throughout. The older SvelteKit app in [`frontend/`](https://github.com/office-rivals/mmr-project/tree/main/frontend) still exists alongside it and uses the same API, but its configuration differs and isn't covered here.

## Core concepts

- **Organization**: the top-level tenant. Each member has a role: owner, moderator or member.
- **League**: a competitive space inside an organization, with a fixed team size such as 2v2.
- **Season**: a period of play within a league. New matches are recorded in the current season.
- **League player**: an organization member who plays in a specific league.
- **Personal access token**: an API credential for scripts and integrations, optionally limited to one organization or league.
